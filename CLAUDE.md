## Always, no exceptions
- One change at a time — make it, stop, let me review before the next. No bundling.
- Surgical find-and-replace only. Never rewrite a whole file/function unless replacing that entire block.
- Diagnose the root cause before changing anything.
- Test on localhost before any git push.
- PowerShell: one command per line; && is not supported.
- Never shortcut mission-critical features — notifications above all.
- Customer-facing copy: first-person singular, formal English, no contractions.
